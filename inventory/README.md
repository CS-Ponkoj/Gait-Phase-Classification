# Project Inventory

This directory contains non-destructive inventory snapshots for the Gait Phase Classification workspace.

No original project file is intentionally moved, renamed, edited, or deleted as part of an inventory snapshot. Generated inventory files are stored under a dated snapshot directory and are excluded from the source-file manifests.

## Available snapshot

- `2026-08-27_initial_snapshot/`: Initial preservation and lineage inventory. Start with `PRESERVATION_REPORT.md`.

## Important limitation

A checksum manifest records identity and detects later changes, but it is not a backup. Raw archives, labeled data, models, code, and reports should also be copied to a separate physical disk or durable managed storage before cleanup or reorganization begins.
